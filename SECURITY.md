# Security Policy

## Reporting a Vulnerability

Do **not** open a public GitHub issue for security vulnerabilities.

Instead, email **security@mkoet.example** with:

- Description of the vulnerability
- Steps to reproduce
- Potential impact
- Suggested fix (optional)

We aim to acknowledge reports within 48 hours.

## Supported Versions

Only the latest release of each MKOET repository is supported with security
updates. Older releases may be patched on a best-effort basis.

## Disclosure Policy

We follow a coordinated disclosure model:

1. Reporter submits details privately
2. We confirm and assess impact
3. Fix is developed and tested
4. Fix is released
5. Public disclosure after 90 days or once a fix is widely deployed,
   whichever comes first

## Scope

This policy applies to all repositories under the `MKOET` organization.

Excluded from scope:

- Third-party dependencies (report those upstream)
- Repositories explicitly marked as archived or experimental
- Social engineering attacks against maintainers
