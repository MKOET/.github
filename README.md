# MKOET Organization Standards

This repository contains organization-wide contribution guidance, governance, security policies, and reusable GitHub community health files.

## Canonical platform analytics

The authoritative home for platform analytics and coding-industry standards is [`platform-analytics/`](platform-analytics/README.md).

- [`platform-analytics/ANALYTICS_STANDARD.md`](platform-analytics/ANALYTICS_STANDARD.md) defines where analytics are stored, how they are published, and privacy/verification requirements.
- [`platform-analytics/standards/CODING_INDUSTRY_STANDARDS.md`](platform-analytics/standards/CODING_INDUSTRY_STANDARDS.md) defines the cross-repository engineering baseline.
- [`platform-analytics/repositories/`](platform-analytics/repositories/README.md) is the canonical index/location for repository-specific analytics.

All platform analyzer and converter workflows must follow this standard. Repository-local copies are not the canonical analytics record.
